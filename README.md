Act as a senior fashion-brand art director, UX designer, frontend developer, and quality engineer.

Design and implement a complete, modern, premium STATIC website for:

THULIR DESIGNER BOUTIQUE
Coimbatore, Tamil Nadu, India.

Do not return only a concept, wireframe, or generic template. Build the actual working website with refined styling, responsive layouts, real approved boutique photography, subtle animations, and working contact links.

The creative direction is an editorial fashion lookbook: expressive photography, elegant typography, generous whitespace, and a confident bridal-and-groom identity.

The business's actual work must be the visual focus.
